# TWO VERSIONS OF THE MACHINE IN ONE BOOK
# These drawings print no section title; several are headed instead with the
# product number they apply to - "For 96041044700" or "For 96041044200", two
# versions of the TS 242D. The mower lift and the cutting deck come once for

# identically). So the product number goes in the title, where a technician
# picking between them can see which is theirs:
#
#   sheet 7   MOWER LIFT - 96041044700
#   sheet 8   MOWER LIFT - 96041044200
#   sheet 10  MOWER DECK - 96041044200
#   sheet 11  MOWER DECK - 96041044700
#
# The chassis sheet is headed "For 96041044700" too, with no counterpart for
# the other version; it keeps its export name. Everything else does too.
